# 1.1.1 更新说明

- DeepSeek 转发稳定性专项优化：重构 Chat Completions 兼容策略，改进 Responses 到 Chat Completions 的工具调用历史拼装、reasoning 回传和 prompt cache 前缀稳定性，减少 DeepSeek thinking 模式下的 400 错误和缓存命中率下降问题。
- Chat Completions API Key 账号兼容性增强：新增按上游自动识别的 provider strategy，覆盖 DeepSeek、MiMo、MiniMax、商汤 SenseNova、Kimi 和通用严格模式，针对不同网关清理不兼容参数、工具定义和消息结构。
- Prompt cache 诊断增强：补充兼容策略、reasoning 来源、placeholder 次数、工具输出补位、前缀 hash、账号粘滞等安全元数据，便于定位上游缓存命中率偏低原因，不展示 reasoning 正文或工具参数全文。
- Codex 项目路由体验修复：写入项目配置时自动生成项目内 `codex-proxy-model-catalog.json`，并在 `.codex/config.toml` 写入 `model_catalog_json`，避免 Codex CLI 对 `cp-route-*` 路由模型提示 fallback metadata warning。
- 项目路由预览与清空优化：项目路由窗口支持同时预览 `config.toml` 和模型 catalog；清空 Codex 项目配置时会移除本软件托管的 catalog，同时保留用户其它 TOML 配置和自定义 catalog。
- 新增桌面 AI 助手窗口：可通过标题栏或菜单打开，用自然语言查看状态、复制接入信息、管理账号、服务控制和项目路由等常用操作。
- 本地服务自动启动更稳：自动启动后增加就绪等待和状态确认，减少服务仍在启动时界面提前加载失败的情况。
