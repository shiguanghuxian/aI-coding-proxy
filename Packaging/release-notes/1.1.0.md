# 1.1.0 更新说明

- 项目路由正式升级：新增独立“项目路由”管理窗口，支持为 Codex 与 Claude Code 按项目目录绑定不同本地代理 Key、账号池和目标模型，适合重度/轻度项目分流使用。
- Claude Code 项目级路由增强：支持写入和清空 `.claude/settings.json` / `.claude/settings.local.json`，自动配置 `ANTHROPIC_CUSTOM_MODEL_OPTION`，新建路由标签默认使用 `claude-cp-route-*`。
- 路由执行更符合项目配置预期：项目路由命中后直接使用规则绑定的本地 Key，不再受当前全局 Key 的账号交集限制；请求日志继续记录项目路由 ID、标签和实际使用的本地 Key。
- 项目配置管理体验优化：项目路由窗口改为左侧列表、右侧详情预览布局，支持查看当前配置、将写入配置、写入项目、清空项目配置、编辑和删除规则，并强化“目标模型”用途说明。
- 总览流量统计增强：新增最近 12 个月按月趋势，并支持折线图、柱状图和混合图切换；修复时间轴柱状图在日/周/月趋势中不显示的问题。
- 本机服务启动更稳：优化 LaunchAgent 启动流程，针对 macOS `launchctl bootstrap` 瞬时 Input/output error 增加恢复判断，减少服务已启动但界面误报失败的情况。
- 打包兼容性改进：macOS App 打包时嵌入 Swift runtime libraries，并清理外部 Swift toolchain rpath，降低在非开发环境机器上运行失败的风险。
