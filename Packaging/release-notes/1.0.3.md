# 1.0.3 更新说明

- OCR 图片上下文增强：为不支持图片上下文的模型新增自动 OCR 注入，覆盖 OpenAI-compatible、Anthropic 和 Gemini 原生链路；支持按图片内容哈希缓存 OCR 结果，减少重复识别。
- OCR 模型管理升级：新增独立 OCR 设置页、OCR 模型管理窗口、本地 MLX OCR 模型选择、下载、校验、删除和测试能力，并支持低资源运行策略和下载进度显示。
- OCR 缓存与日志：新增 OCR 缓存与识别日志窗口，可查看安全元数据、查看缓存中的识别结果、清理 OCR 缓存和识别日志。
- 请求诊断与状态刷新：新增安全请求体诊断日志开关，可在请求日志中查看最终上游请求体；状态栏 token 用量支持请求完成后的事件触发刷新。
- 账号与配置改进：账号池支持批量移除；Google/Gemini OAuth Client ID 和 Secret 改为设置页配置；Chat Completions API Key 账号支持 Vision 开关和 reasoning_effort 映射。
- 图片与测试控制台：Images API 支持 `/v1/images/edits`，图片结果支持另存为和大图查看。
- 构建与打包优化：本地打包脚本支持单架构快速模式，并缓存 App 图标、本地 MLX OCR helper 和 MLX metallib 等固定构建步骤。
- 兼容性与稳定性：完善 DeepSeek/小米 MiMo thinking mode 的 reasoning_content 回传与持久化清理能力，优化缓存隔离、清理入口和相关提示。
